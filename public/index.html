Revenue Loop

Each lead moves from list to closed deal through a fixed transition table, and every step needs evidence. Campaigns start only after three gates pass. Every won deal becomes the seed of a new lookalike list, so revenue can be traced back to the list it came from.

Try it in one minute

  1. Lists: click Score companies and Check emails on List A and List B.
  2. Campaign: pick List B, Run gates, then Start campaign. It is blocked, with the reason.
  3. Switch to List A, run the gates again and start the campaign.
  4. Leads: open Move to… on one List A lead and walk it to closed_won. Try skipping a step: the table refuses it. The won deal seeds a new lookalike list, and the report shows revenue per list.
